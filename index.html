Publish on GitHub Pages

Create a public repository, such as wedding-invitation. Upload index.html and the assets folder together. In GitHub, open Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save. Your website will appear at https://YOUR-USERNAME.github.io/wedding-invitation/. You can edit text directly on the website, but edits are saved only in your current browser. To make edits permanent for every visitor, update the text inside index.html and commit that file to GitHub. For a paper copy, use Print / Save as PDF.
